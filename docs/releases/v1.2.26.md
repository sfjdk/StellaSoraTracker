# v1.2.26 · 三套主题与完整功能整合

- 新增「星轨夜航」「晴空工作台」「旅人手札」三套界面，均使用左侧导航。
- 在「数据与设置 → 界面主题」切换外观，重启后自动恢复上次选择；切换主题保留当前页面、筛选和搜索状态。
- 主操作统一为「抓取抽卡记录」。整合 v1.2.25 的多账号、UID 与分享文件、三服识别、导入导出、备份及网页版账户功能。
- 保留旧版归档迁移与账号隔离，防止导入和再次抓取时混合不同账号的记录。
- 修复发行构建中的旧机器路径、打包目录和更新地址配置，发行包排除本地账号、归档及个人设置。

下载 `StellaSoraGachaTool-1.2.26-win64.zip`，完整解压后运行文件夹中的 `StellaSoraGachaTool.exe`，无需安装 Python。读取游戏时按提示以管理员身份运行，并先在游戏中打开需要读取的招募记录。

从旧版升级前请备份原程序目录中的 `exports` 文件夹；解压新版后，将原 `exports` 文件夹复制到新版程序旁，即可继续使用本地账号和历史记录。

校验文件：`SHA256SUMS.txt`。本次已通过 297 项自动测试，以及发行程序三套主题、五个页面的离线启动与渲染检查。实际游戏内读取及线上账户服务需要对应运行环境，未进行实机联调。
